## 👋 About me

Fullstack developer from **Ribeirão Preto, SP — Brazil**, focused on shipping real products end to end — from the database to deploy.

I build backends in **Go** and **TypeScript (Bun + Fastify)**, frontends with **React + TypeScript**, and self-host everything on Linux with Docker. I like automating infra, running my own services (mail server, internal APIs) and wiring **AI agents** into practical workflows.

Currently building:
- 🏗️ **santos-tech** — central API and ecosystem (Go + Bun/Fastify/Drizzle), self-hosted mail server and an internal agent that orchestrates Claude Code
- 🎮 **Santos Games Arena** — a full esports tournament platform (Valorant, CS, LoL) with multiple championship sites, an admin portal and a Telegram/WhatsApp bot
- 🎓 **Inter UnaERP** — university championship ecosystem (Go API + React Web) integrated with Santos Games Arena
